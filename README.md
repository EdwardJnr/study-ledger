# Study Ledger

My study tracker. It installs on an iPhone from its own home-screen icon, opens full screen and works offline.

## Publish it (one time, about five minutes)

1. Unzip this folder.
2. Sign in to github.com, then tap **+** → **New repository**. Name it `study-ledger`, set it to **Public** and tap **Create repository**.
3. Tap **uploading an existing file**, drag in everything from this folder (index.html, manifest.webmanifest, sw.js, README.md and the `icons` folder), then tap **Commit changes**.
4. Open **Settings → Pages**. Under **Branch**, choose `main` and `/ (root)`, then tap **Save**.
5. After a minute or two the app is live at `https://<your-username>.github.io/study-ledger/`.

## Install on iPhone (iOS 16.4 or later)

1. Open that address in Chrome or Safari.
2. Tap Share → **Add to Home Screen** → **Add**.
3. Open it from the new icon from now on.

Progress is stored on the phone, inside the installed app. Use **Export backup** now and then and save the file to Files or iCloud Drive.
